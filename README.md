This app is a panel of Django Automated Tasks. It has the purpose of showing that daily boring tasks can be done in different ways by using Django and Python.

You can do lots of things from uploading/exporting info from tables on a database, to send bulky emails to lots of users and even track those emails. (Percentage of opening and click rate),
compress images to reduce their size while still keeping a good image quality and even analyze/query the stock market for a specific company that you are interested in.

Some process can be notified to the user, for example:
  - When importing/exporting you are notified, and once the process is finished, you are delivered the file(s) into your personal email.


This project made use of Django custom commands, celery, redis, web scraping, bootstrap, etc.
